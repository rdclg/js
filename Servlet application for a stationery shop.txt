 Create a Servlet application for a stationery shop that accepts the prices
of two items and displays their sum, difference, product and division.
Technology: Servlet
Where to write: src/java/StationeryServlet.java
Easy explanation: It reads two item prices and shows four arithmetic results.
Code
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.*;
@WebServlet("/stationery")
public class StationeryServlet extends HttpServlet {
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws IOException {
        response.setContentType("text/html;charset=UTF-8");
        PrintWriter out = response.getWriter();
        out.println("<h2>Simple Form</h2>");
        out.println("<form method='post'>");
        out.println("<label>Pen price: <input type='number' name='a' required></label><br>");
        out.println("<label>Notebook price: <input type='number' name='b' required></label><br>");
        out.println("<button type='submit'>Submit</button></form>");
    }
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws IOException {
        response.setContentType("text/html;charset=UTF-8");
        PrintWriter out = response.getWriter();
        double a = Double.parseDouble(request.getParameter("a"));
        double b = Double.parseDouble(request.getParameter("b"));
        out.println("Sum = " + (a+b) + "<br>");
        out.println("Difference = " + (a-b) + "<br>");
        out.println("Product = " + (a*b) + "<br>");
        if (b != 0) out.println("Division = " + (a/b));
        else out.println("Division not possible: second price is zero");
    }
}
Sample output: Prices 20 and 5 -> Sum 25, Difference 15, Product 100, Division 4.0
How to run: Open `/stationery` and enter two prices.
Viva question: What is the modulus operator?
Viva answer: It gives the remainder after division, written `%`.
