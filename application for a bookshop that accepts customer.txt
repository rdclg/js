 Create a Servlet application for a bookshop that accepts customer
details and stores them in a database using JDBC.
Technology: Servlet + JDBC
Where to write: src/java/BookshopCustomerServlet.java; MySQL table `customers`
Easy explanation: Customer details are inserted into the database with a prepared statement.
